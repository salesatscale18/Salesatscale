# Sales at Scale

Landing page for Sales at Scale — a single, self-contained `index.html` (no build step).

## Run locally

Open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
```

## Deploy

Works as-is on GitHub Pages, Vercel or Netlify — point the host at the repo root.
